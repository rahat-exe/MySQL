# Main difference between Procedure and Function
| Procedure                  | Function                      |
| -------------------------- | ----------------------------- |
| Performs actions           | Returns a value               |
| May or may not return data | Must return one value         |
| Called using `CALL`        | Called inside SQL expressions |
| Can use OUT parameters     | Cannot use OUT parameters     |
| Used for large operations  | Used for calculations         |
